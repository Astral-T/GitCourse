# Reglas de Control de Versiones (Git)

1. **Compromiso de Guardado:** Al finalizar cualquier modificación de archivos, refactorización o diseño, es OBLIGATORIO que verifiques el estado de Git.
2. **Confirmación con el Usuario:** Antes de dar por terminada una tarea en el chat, debes proponerle al usuario registrar los cambios. 
3. **Formato Profesional:** Debes estructurar el mensaje bajo la convención de 'Conventional Commits' (ej. `feat: diseñar sección de noticias`).
4. **Acción:** Pregunta explícitamente: "He terminado los cambios. ¿Deseas que ejecute el commit automáticamente o prefieres registrarlo tú desde Git Bash?".
